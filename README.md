# Next.js × Supabase × Stripe セキュリティ診断チェックリスト

[ハロテック（hellotech）](https://www.youtube.com/@ハロテック) の公開ナレッジです。Next.js（App Router）・Supabase・Stripe で作った小規模 SaaS を、**自分の資産**として点検したときに使ったチェックリストと、サンプル報告書を置いています。

これは「どう作るか」ではなく「作ったあとに、どこを点検するか」のための資料です。AI でコードを速く書けるようになったぶん、点検の観点を一枚にまとめておくと、見落としが減ります。

## 中身

| ファイル | 内容 |
| --- | --- |
| [`checklist.md`](./checklist.md) | 診断チェックリスト（認証・RLS・API・Stripe・ヘッダー・依存関係など） |
| [`samples/report-lab.md`](./samples/report-lab.md) | 練習用アプリ（OWASP Juice Shop / DVWA）に対する非破壊スキャンの報告書サンプル |
| [`samples/report-payment.md`](./samples/report-payment.md) | 自作 SaaS（Payment）のソースコード診断の報告書サンプル（一部匿名化） |
| [`SECURITY.md`](./SECURITY.md) | この資料の対象範囲と取り扱いの方針 |

## 使い方

1. `checklist.md` の各項目を、自分のコード・設定画面と突き合わせて確認します。
2. 見つかった指摘は、重大度（高・中・低）と「どう直すか」をセットで記録します。
3. サンプル報告書の構成（概要 → 範囲 → 指摘事項 → 確認方法）を、自分の報告書の型として流用できます。

## 対象と免責

- この資料と手順は、**自分が所有する資産、または書面で許可を得た対象**に対してのみ使ってください。
- 無許可の検査は、不正アクセス禁止法などに触れるおそれがあります。
- サンプル報告書は、脆弱性の「仕組み」と「直し方」を説明するためのものです。**攻撃の再現手順は含みません。**
- 練習用アプリ（Juice Shop / DVWA）は、学習用にわざと脆弱に作られたアプリです。実在のサービスではありません。
- 結果は確認時点のものであり、問題がないことを保証するものではありません。
