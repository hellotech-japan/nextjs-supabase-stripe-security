# 非破壊スキャン報告書（サンプル：練習用アプリ）

> **この報告書について**
> 学習用にわざと脆弱に作られた練習用アプリ（OWASP Juice Shop / DVWA）を対象に、localhost の隔離ラボ内で、非破壊（passive_only）スキャンのみで実施した結果を、サンプルとして整形したものです。実在のサービスではありません。攻撃の再現手順は含みません。

- **作成日時**: 2026-10-14
- **診断対象**: 練習用アプリ（Juice Shop は `localhost:3000`、DVWA は `localhost:8080`）
- **使用ツール**: nmap / httpx / nuclei / OWASP ZAP

能動（攻撃的）スキャンは使っていないため、踏み込んで初めて分かる脆弱性はこの診断の範囲外です。それでも、受動スキャンだけで設定の抜けがこれだけ出ます。検出された項目は、練習用アプリに仕込まれた学習用の意図的な脆弱性を含みます。

## 3. 低：ヘッダー不足とCookie属性が中心

低の 21 件は、ZAP の受動スキャンが中心です。種類で整理すると次の 3 つに分かれます。

| 種類 | 代表的な項目 |
| --- | --- |
| セキュリティ関連ヘッダーの不足 | CSP 未設定、X-Content-Type-Options 未設定、クリックジャッキング対策ヘッダーなし、COEP・Permissions-Policy の不備 |
| Cookie の属性不足 | HttpOnly なし、SameSite なし |
| 情報の露出 | Server ヘッダーのバージョン露出、バナーの情報漏れ、タイムスタンプの露出 |

これらは、外から応答ヘッダーを見れば分かる、設定の抜けです。コードを読むより、動かして確かめるほうが速い種類です。

## 4. 人がやった判定：情報レベルを外す

ZAP の出力には、脆弱性ではない「情報」も混じります。たとえば「Modern Web Application」「Authentication Request Identified」「Session Management Response Identified」「Non-Storable Content」は、アプリの作りや通信を検出しただけで、直す対象ではありません。報告書では、これらを情報レベルとして分け、対応が要る指摘（ヘッダー不足、Cookie 属性、メトリクス公開）と区別しました。この仕分けが、自動スキャンをそのまま出すのとの差です。
